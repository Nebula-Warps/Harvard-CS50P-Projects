# Harvard CS50P: Introduction to Programming with Python

This repository contains all my problem sets, labs, and the final project completed during Harvard University's CS50P course. 

## Tech Stack
*   **Language:** Python 3
*   **Libraries:** `csv`, `sys`, `re`, `random`, `pytest` (and any others you used)

## What I Learned
Completing this course taught me how to think like a programmer. Key skills I developed include:
*   Writing clean, readable Python code using functions and classes.
*   Handling exceptions and debugging code without panicking.
*   Validating data using Regular Expressions (Regex).
*   Writing unit tests with `pytest` to ensure code reliability.
*   Reading and writing files (JSON, CSV).

## Repository Structure
Here is a quick guide to what is inside this repo:
*   `/psets` - Problem sets from Weeks 0 through 9 (covering loops, functions, OOP, files, and more).
*   `/final_project` - The final project (see specific README inside the folder for details).
